# Davonn Lemuel Halomoan: Portfolio

Live site: https://davonnlemuel.github.io

My data analyst portfolio. It has projects in Python, Power BI, Tableau and Excel, actuarial work from my Mathematics degree at Universitas Katolik Parahyangan, and assignments from the Dibimbing Data Analytics and Business Intelligence bootcamp. The site is in English and Indonesian.

## Files

- `index.html`: the whole site, one page
- `app.js`: charts, project picker and Indonesian translations
- `styles.css`: layout and styles
- `assets/`: logos, images, certificates and chart data

## Run it locally

```
python -m http.server 8000
```

Then open http://localhost:8000.
